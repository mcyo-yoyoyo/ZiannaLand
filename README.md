# Zianna Land

为 7 岁、已有约一年英语学习经验的 Zianna 设计的设备本地儿童英语课程。第三阶段在 60 节日课、24 本分级读物和 12 个每周作品之上，加入 12 个安全可控的角色对话主题。

## 已实现

- 6 题首次能力测评，推荐「种子 / 新芽 / 探索者」起点
- 每天 1 节新课，并在掌握后的第 1、3、7 天安排复习
- 听音选择、中英配对、拼读发现、句子排序、故事排序、口语表达 6 种互动
- 每课记录掌握分数；80 分以上进入下一课，未掌握时安排巩固
- 麦克风录音、设备本地声音作品库和家长周报
- PWA 安装清单与离线缓存；断网时可启动并完成图文课程
- 无强制账号、无广告；进度保存在当前浏览器
- Zianna、Sprig、Pip、Momo 四位连续角色与 12 章故事主线
- 24 本分级短读物，每个阶段 8 本，支持整篇朗读、点词发音和理解题
- 根据最近 5 次表现自动切换陪伴、稳步或挑战模式，并优先复习薄弱能力
- 每周完成一个可保存的英语作品；课堂与读物都能录制孩子自己的旁白
- 12 个角色对话主题、36 轮递进问答，全部围绕课程目标词和核心句型
- 根据孩子的回答继续追问，标记已经使用和遗漏的关键表达
- 支持文字、示例句和浏览器语音识别三种回答方式
- 家长页自动生成下一步建议，关联本周时长、薄弱能力和对话漏词
- 发音优先使用可跨浏览器播放的自然美式 MP3，首次联网播放后自动缓存在设备；浏览器语音仅作备用
- Wikimedia 视频会自动选择设备支持的 MPEG-4 转码并在课内播放，同时保留 WebM 备用源

## 本地运行

直接打开 `index.html` 可以体验核心课程。安装到设备和离线缓存需要通过 HTTP 或 HTTPS 访问，例如在项目目录运行：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。

## 项目结构

- `index.html`：页面结构
- `app.css`：视觉与响应式布局
- `app.js`：测评、日课、自适应、阅读、作品、复习、报告与录音逻辑
- `content/program.js`：12 周课程与故事世界数据
- `content/readers.js`：24 本分级阅读数据
- `content/dialogues.js`：12 个可控角色对话脚本与目标表达
- `assets/zianna-land-characters-v2.png`：原创角色组合插画
- `content/manifest.json`：课程版本与能力配置
- `manifest.webmanifest`、`sw.js`：安装和离线支持
- `index.phase3-backup.html`、`app.phase2.js`、`app.phase2.css`：第三阶段升级前备份

## 内容与数据

自然发音和开放版权视频首次使用时需要联网，已经播放的发音会缓存在当前设备。视频作者、来源页和许可证会显示在课内。学习记录使用 `localStorage`，声音作品使用 `IndexedDB`。角色对话不调用开放式大模型，问题和反馈限制在课程词汇内；浏览器语音识别在部分设备上可能需要联网。家长页可以导出 JSON 学习记录或清除本地数据。
